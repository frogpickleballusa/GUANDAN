# Guandan Table

Online Guandan for 4, 6 or 8 players (one deck per two players, two teams sitting alternately).
Anyone with the invite link can play; no accounts. Each phone only receives its own cards, and a
Supabase server function checks every move.

- `docs/` is the website (served by GitHub Pages).
- `supabase/setup.sql` creates the tables (run once).
- `supabase/functions/game/index.ts` is the server function (generated by `build.py` from `src/`).

## One-time setup

1. **Supabase project**: create a free project at supabase.com.
   - Authentication → Sign In / Providers → turn on **Allow anonymous sign-ins**.
   - SQL Editor → paste all of `supabase/setup.sql` → Run.
2. **Server function**, either:
   - **Automatic (recommended):** in GitHub → Settings → Secrets and variables → Actions, add
     `SUPABASE_ACCESS_TOKEN` (from supabase.com/dashboard/account/tokens) and
     `SUPABASE_PROJECT_REF` (the part before `.supabase.co` in your project URL). Then
     Actions → "Deploy game function" → Run workflow.
   - **By hand:** Supabase → Edge Functions → Deploy a new function → Via editor, name it `game`,
     paste all of `supabase/functions/game/index.ts`, Deploy.
3. **Website config**: put your project URL and anon (public) key in `docs/config.js`.
4. **GitHub Pages**: repo Settings → Pages → Deploy from a branch → `main`, folder `/docs`.

The free Supabase plan pauses a project after a week with no activity; restore it from the dashboard.

## Changing the game

Edit `src/engine.js` (rules), `src/core.js` (server actions) or `docs/index.html` (the page), then run
`python3 build.py` to regenerate the function and copy the engine into `docs/`.
